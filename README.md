# LeetCode Sign Up Page Clone

A front-end clone of the LeetCode Sign Up/Login page created using **HTML and CSS**.

This project was developed as a practice project to improve my understanding of HTML structure, CSS styling, layouts, navigation elements, forms, and responsive webpage design.

## 🚀 Features

* LeetCode-inspired dark user interface
* Navigation bar with multiple sections
* Search bar UI
* Premium button
* Username/Email and Password input fields
* Cloudflare verification-style section
* Social login icons for Google, GitHub, Apple, and LinkedIn
* Forgot Password and Sign Up links
* Footer section with additional links
* LeetCode-inspired layout and styling

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome

## 🎯 Purpose

The purpose of this project is to practice front-end web development by recreating the visual layout of an existing website using HTML and CSS.

The project focuses on understanding:

* HTML page structure
* CSS layouts and positioning
* Flexbox
* Forms and input fields
* Navigation bars
* Linking external pages
* Using images and icons
* Styling different webpage components
